# Design System

## Purpose

This document defines the visual language of the portfolio.

Its purpose is to ensure every page and component feels like part of the same product.

The design system should prioritize clarity, consistency, usability, and engineering-focused storytelling over visual complexity.

---

# Design Philosophy

The portfolio should feel:

- Calm
- Premium
- Modern
- Minimal
- Purposeful
- Fast
- Professional

Every design decision should support the content rather than compete with it.

Projects should remain the visual focus throughout the experience.

---

# Design Principles

## 1. Engineering First

Design exists to help visitors understand the work.

The interface should never become the main attraction.

---

## 2. Simplicity Before Decoration

Whitespace, typography, and hierarchy are preferred over decorative graphics.

If an element does not improve usability or communication, it should not exist.

---

## 3. Consistency Creates Trust

Every page should follow the same visual language.

Spacing, typography, colors, buttons, and interactions should remain consistent.

---

## 4. Motion Has Purpose

Animations should provide:

- feedback
- continuity
- context

Animations should never slow down the experience.

---

## 5. Readability Above All

Content should always remain easier to read than it is to admire.

---

# Visual Identity

The portfolio should communicate:

Professional Engineer

↓

Modern Builder

↓

Thoughtful Problem Solver

↓

Creative but Practical

# Typography

## Primary Typeface

Geist

Used for:

- Headings
- Navigation
- Buttons
- Labels
- Titles

---

## Secondary Typeface

Inter

Used for:

- Paragraphs
- Case Studies
- Project Descriptions
- Long-form Reading

---

# Typography Principles

Typography should:

- establish hierarchy
- improve readability
- create rhythm
- remain spacious

Avoid decorative typography that reduces clarity.

---

# Color Philosophy

The color palette should communicate:

- warmth
- confidence
- simplicity
- calmness

Avoid highly saturated colors.

# Color Rules

Accent colors should guide attention.

They should never dominate the page.

Color should communicate hierarchy rather than decoration.

---

# Spacing System

The interface should use generous whitespace.

Spacing should create breathing room between sections.

The portfolio should feel uncluttered.

Use a consistent spacing scale throughout the application.

---

# Corner Radius

Buttons

Medium rounded corners

Cards

Large rounded corners

Images

Soft rounded corners

Avoid sharp edges unless required for usability.

---

# Shadows

Shadows should remain subtle.

Components should appear lightly elevated rather than floating dramatically.

Avoid dark or oversized shadows.

---

# Icons

Use clean outlined icons.

Icons should support understanding rather than decorate empty space.

---

# Buttons

Buttons should be simple and readable.

Primary buttons should attract attention.

Secondary buttons should remain subtle.

Avoid oversized call-to-action buttons.

---

# Images

Images should:

- remain high quality
- support the content
- avoid unnecessary decoration

Project previews should remain the primary visual assets.

---

# Motion Philosophy

Motion should communicate:

- interaction
- continuity
- responsiveness

The interface should remain calm while idle.

Interaction should create delight.

---

# Accessibility

Every visual decision should consider:

- contrast
- readability
- keyboard navigation
- reduced motion
- focus visibility

Accessibility is a requirement, not an enhancement.

---

# Responsive Design

Every screen should be intentionally designed for:

- Desktop
- Laptop
- Tablet
- Mobile

Responsive layouts should adapt rather than simply shrink.

---

# Things We Intentionally Avoid

The portfolio should avoid:

- excessive gradients
- neon color palettes
- distracting animations
- unnecessary visual effects
- information overload
- decorative components without purpose

---

# Definition of Success

The design system succeeds when:

- every page feels visually connected
- projects remain the primary focus
- visitors never feel overwhelmed
- interactions feel natural
- the interface supports the engineering story
