# Typography System

## Purpose

This document defines the typography system for Portfolio 2026.

Typography should establish visual hierarchy, improve readability, and communicate professionalism.

Since the portfolio is engineering-focused, typography plays a larger role than decorative visuals.

The goal is to make technical content enjoyable to read while maintaining a clean and premium appearance.

---

# Typography Philosophy

Typography should feel:

- Calm
- Modern
- Spacious
- Professional
- Timeless

It should never become decorative.

Good typography should disappear into the experience and allow the content to take center stage.

---

# Font Families

## Primary Typeface

**Geist**

Purpose

- Headlines
- Navigation
- Buttons
- Labels
- Cards
- Section Titles

Reason

Geist is clean, modern, and highly readable while maintaining a technical aesthetic.

---

## Secondary Typeface

**Inter**

Purpose

- Paragraphs
- Project Case Studies
- Long-form Reading
- Descriptions
- Metadata

Reason

Inter is optimized for digital reading and provides excellent readability across all screen sizes.

# Font Weight Rules

Light

Use sparingly.

Only for large display typography if required.

---

Regular

Primary weight for body content.

---

Medium

Navigation

Buttons

Labels

---

Semi Bold

Section headings

Important labels

---

Bold

Only for emphasis.

Avoid excessive bold text.

---

# Line Height

Typography should remain airy.

Long-form content should prioritize comfortable reading over compact layouts.

Avoid dense text blocks.

---

# Letter Spacing

Large headings may use slightly tighter spacing.

Body text should remain natural.

Do not artificially increase spacing unless it improves readability.

---

# Reading Width

Long paragraphs should never stretch across the full screen.

Maintain a comfortable reading width to reduce eye fatigue.

Case studies should prioritize readability over maximum content density.

---

# Text Alignment

Left alignment should be the default throughout the portfolio.

Centered text should be used only where it strengthens the visual hierarchy, such as the Hero section.

Avoid justified text.

---

# Typography Rules

✔ Maintain a clear visual hierarchy.

✔ Keep paragraphs concise.

✔ Use whitespace to separate ideas.

✔ Allow typography to breathe.

✔ Maintain consistent spacing between headings and content.

---

# Things We Intentionally Avoid

- Decorative fonts
- Multiple font families
- Excessive bold text
- All-uppercase paragraphs
- Extremely thin fonts
- Inconsistent heading styles

---

# Accessibility

Typography should remain readable across all supported devices.

Text should maintain sufficient contrast against backgrounds.

Font sizes should never become too small for comfortable reading.

Reading should remain effortless on desktop, tablet, and mobile devices.

---

# Future Expansion

If additional typography styles are required in future versions, they should extend this system rather than replace it.

Consistency should always take priority over introducing new styles.

---

# Acceptance Criteria

The typography system is considered complete when:

✓ Every page follows a consistent hierarchy.

✓ Long-form reading remains comfortable.

✓ Headings clearly establish information hierarchy.

✓ Typography supports the engineering-first identity of the portfolio.

✓ The interface feels calm, modern, and professional.
